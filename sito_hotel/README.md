# Sito Web - Hotel Splendid

Questo progetto contiene la parte statica in HTML del Project Work.

## Contenuto
- `index.html`: Home page
- `camere.html`: Dettaglio camere
- `servizi.html`: Servizi hotel
- `contatti.html`: Info e contatti
- `prenotazione.html`: Link all'app di prenotazione
- `style.css`: Fogli di stile
- `ARCHITETTURA_SITO.md`: Documentazione architetturale

## Istruzioni
Aprire `index.html` in un browser per visualizzare il sito.
