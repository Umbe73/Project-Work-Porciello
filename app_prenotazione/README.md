# Applicativo di Prenotazione - TypeScript

Applicativo logico per la gestione e validazione delle prenotazioni dell'Hotel Splendid.

## Tecnologie
- TypeScript
- Vite (per il build e il server locale)
- HTML/CSS

## Funzionalità
- Controllo capienza camere in base al numero di ospiti.
- Verifica durata del soggiorno.
- Feedback dinamico all'utente.

## Istruzioni per l'uso locale
1. Entrare nella cartella `app_prenotazione`.
2. Eseguire `npm install` per installare le dipendenze.
3. Eseguire `npm run dev` per avviare il server di sviluppo.
4. Eseguire `npm run build` per generare i file statici.
